# Open Questions

## 1. Purpose

The baseline is intentionally opinionated, but some questions are genuinely unresolved. This list is the honest backlog of decisions that need evidence or a named owner.

**Rule:** an open question is not a blocker unless it appears in a phase gate. Each has an owner and a deadline.

## 9. How questions get closed

1. Assign an owner and a decision date.
2. Gather evidence (experiment, pilot, legal review, simulation).
3. Write a decision in the [decision log](03-decision-log.md).
4. Update affected docs and requirements.
5. Remove the question from this list.
