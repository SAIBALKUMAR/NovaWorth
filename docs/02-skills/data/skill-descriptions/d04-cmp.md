## Computing & Software (CMP)

**CMP-01 · Computer literacy.** Confident, safe command of everyday computing. From files and apps to troubleshooting any common environment and teaching digital literacy.

**CMP-02 · Operating systems.** How a machine manages its own resources. From navigating an OS to diagnosing OS-level performance and security issues.

**CMP-03 · Internet & web.** How the network and the browser actually work. From using the web to explaining and debugging web protocols end to end.

**CMP-04 · Programming fundamentals.** Turning a problem into code that runs. From first functions to writing clean, tested code in unfamiliar languages.

**CMP-05 · Python.** Deep fluency in the most versatile language. From first scripts to building production Python systems and teaching advanced Python.

**CMP-06 · Data structures & algorithms.** Organizing data and reasoning about efficiency. From lists and sorting to solving novel problems at competitive-programming level.

**CMP-07 · Software design.** Structuring code so it can grow and change. From clean modules to designing maintainable systems under real constraints.

**CMP-08 · Version control.** Managing change across a codebase and a team. From commits to running release workflows for large distributed teams.

**CMP-09 · Testing & QA.** Proving software does what it should. From writing a test to designing test strategies that catch critical defects at scale.

**CMP-10 · Databases.** Storing and querying data reliably. From a first table to designing and tuning databases for high-scale workloads.

**CMP-11 · APIs & integration.** Making systems talk to each other. From calling an API to designing API ecosystems used by thousands of developers.

**CMP-12 · Frontend development.** Building the interfaces people actually use. From a first page to building accessible, high-performance interfaces at scale.

**CMP-13 · Backend development.** Building the services behind the screen. From a first server to building resilient backend systems under heavy load.

**CMP-14 · Mobile development.** Shipping software that lives in a pocket. From a first app to shipping mobile apps with excellent performance and accessibility.

**CMP-15 · Cloud & DevOps.** Delivering and operating software continuously. From deployment basics to designing multi-cloud delivery platforms with strong reliability.

**CMP-16 · Cybersecurity.** Protecting systems, data, and people. From safe habits to leading security architecture and incident response.

**CMP-17 · Networking.** How machines find and reach each other. From local networks to diagnosing and designing networks at carrier scale.

**CMP-18 · Systems programming.** Code that runs close to the hardware. From pointers to writing safe, high-performance systems code.

**CMP-19 · Distributed systems.** Software that spans many machines. From basic services to designing fault-tolerant distributed systems at global scale.

**CMP-20 · Performance engineering.** Making fast software faster. From profiling to finding and fixing bottlenecks at the limits of hardware.

**CMP-21 · Site reliability.** Keeping services alive and trustworthy. From monitoring to running SRE programs for critical services.

**CMP-22 · Game development.** Building interactive experiences that feel good. From a first prototype to shipping games with polished systems and performance.

**CMP-23 · Embedded systems.** Software inside physical devices. From blinking an LED to building reliable embedded systems under power constraints.

**CMP-24 · Compiler design.** Building the programs that build programs. From parsing to designing and optimizing language compilers.

**CMP-25 · Large-scale architecture.** Systems that serve the whole world. From basic scaling to architecting systems serving billions of users.
