# Exemplar: Computing & Software (CMP-25)

## 1. Why this exemplar

Computing & Software is the flagship ladder because it shows the full arc the user described: from "what is a computer" to designing a Facebook-scale system and handling live incidents. It also demonstrates how knowledge, artifacts, simulations, and panels combine at the top.

**Skill ID:** `CMP-25`  
**Domain:** Computing & Software  
**Archetype:** Technical  
**Domain multiplier:** 1.20  
**Level 100 outcome:** Architects systems serving billions of users and advances the field through original, verified contribution.

---

## 2. The 10 bands

| Band | Levels | Identity | What changes |
|---|---|---|---|
| 1 | 1–10 | Foundation | From zero to safe, confident computer use |
| 2 | 11–20 | Literacy | From user to programmer |
| 3 | 21–30 | Practitioner | From scripts to algorithms and data |
| 4 | 31–40 | Builder | From code to production systems |
| 5 | 41–50 | Specialist | From systems to data and ML |
| 6 | 51–60 | Professional | From ML to LLM agents and products |

## 3. Full 100-level ladder

### Band 1 — Foundation (1–10)

| Level | Title | What the learner can do | Gate proof |
|---:|---|---|---|
| 1 | Computer information & hardware | Identify CPU, RAM, storage, GPU, ports, and peripherals; explain what each does | Label a machine and explain a spec sheet |
| 2 | Operating system operations | Install apps, manage users, updates, settings, and storage | Configure a fresh machine to a checklist |
| 3 | Files, folders & backups | Organize files, compress, restore, and verify backups | Recover a deleted file and restore a backup |
| 4 | Internet, browsers & email | Explain DNS/URLs, use browsers safely, recognize phishing | Diagnose connectivity and classify 10 emails |
| 5 | Typing & shortcuts | Type 40+ WPM and use 20+ OS/app shortcuts | Timed typing + shortcut task |
| 6 | Command line basics | Navigate, create, move, inspect permissions, and read errors | Complete a 15-command shell task |
| 7 | Text editors & Markdown | Edit code/config files and write structured docs | Create a README and a config file |
| 8 | Productivity suites | Build a spreadsheet with formulas, a document, and a deck | Budget sheet + 5-slide deck |
| 9 | Digital security hygiene | Use password managers, 2FA, updates, and safe browsing | Secure a device and pass a phishing audit |
| 10 | Troubleshooting & help-seeking | Isolate faults, read logs, search effectively, ask a good question | Diagnose 3 seeded faults and write a report |

**Band 1 gate:** a 30-minute practical "set up and repair a machine" exam plus a 20-item quiz. Pass 80%.

### Band 2 — Programming literacy (11–20)

| Level | Title | What the learner can do | Gate proof |
|---:|---|---|---|
| 11 | Programming concepts | Use variables, types, conditionals, loops, and functions | 20 auto-graded exercises |
| 12 | Python basics | Write functions, use lists/dicts, read/write files | CLI tool that processes a CSV |
| 13 | Control flow & functions | Decompose problems, handle edge cases, avoid duplication | 15 problems + code review |
| 14 | Collections & files | Use lists, dicts, sets, JSON, CSV, and exceptions | Data-cleaning script with tests |
| 15 | Errors, debugging & testing | Read tracebacks, use a debugger, write unit tests | Fix a buggy repo and add tests |
| 16 | Git & GitHub | Commit, branch, merge, resolve conflicts, open a PR | Contribute a real PR |
| 17 | HTML & CSS | Write semantic, responsive, accessible markup | Portfolio page, mobile + desktop |
| 18 | JavaScript basics | Manipulate the DOM, handle events, fetch data | Interactive page with API data |
| 19 | APIs & JSON | Use HTTP verbs, auth, pagination, retries, errors | API client with error handling |
| 20 | Automation project | Automate a real personal or work workflow | Documented automation + demo |

**Band 2 gate:** a small full-stack app (frontend + API) with tests and a README. Oral defense: "why this design?"

### Band 3 — Core CS & DSA (21–30)

|---:|---|---|---|

| 26 | Sorting & searching | Implement, compare, and choose algorithms | Benchmark + 15 problems |
| 27 | Dynamic programming | Recognize substructure and build DP solutions | 15 problems |
| 28 | Databases & SQL | Design schemas, write joins, index, use transactions | Design + query a real DB |
| 29 | OOP & design patterns | Use interfaces, composition, and SOLID responsibly | Refactor a project + review |
| 30 | DSA capstone | Solve 100 graded problems and explain patterns | Repo + performance report + oral |

**Band 3 gate:** 100-problem portfolio with at least 30 medium/hard, plus a 45-minute unseen problem and oral defense. Pass 80%.

### Band 10 — World-class (91–100)

| Level | Title | What the learner can do | Gate proof |
|---:|---|---|---|
| 91 | Frontier architecture | Design AI-native, edge, and serverless systems | Position paper + review |
| 92 | Formal methods & verification | Specify and verify critical protocols | TLA+ model + proof |
| 93 | Performance at hardware limits | Profile, optimize memory, SIMD, and I/O | Benchmark + writeup |
| 94 | AI-assisted software factory | Build agent pipelines with evals and guardrails | Working factory |
| 95 | Open-source leadership | Maintain a project and govern contributors | Maintainer evidence |
| 96 | Standards & governance | Write or shape an RFC/standard | Adopted standard |
| 97 | Mentoring senior engineers | Develop other senior engineers | Mentee outcomes |
| 98 | Research & invention | Produce a novel, defensible contribution | Paper/patent + review |
| 99 | Industry strategy | Make build/buy/org/market decisions | Strategy + panel |
| 100 | Grandmaster | Original contribution with verified global impact | Portfolio + panel + impact |

**Level 100 standard:** the learner must submit:
1. A portfolio of 3–5 systems they designed or led.
2. Evidence of real-world impact (scale, adoption, reliability, cost, safety).
3. An original contribution (paper, open-source project, standard, or invention).
4. Two external expert references.
5. A 90-minute oral defense with a 5-person panel.
6. A public case study (with consent).

The panel scores: technical depth, judgment under uncertainty, impact, teaching, and ethics. Passing requires 4/5 on every dimension.

## 6. Anti-gaming notes

- Code artifacts are run against hidden tests and reviewed for provenance.
- Oral defense at every band gate from 20 onward.
- Live-fire sims use randomized failure injection.
- Level 90+ requires external panel and real-world evidence.
- AI assistance is allowed where declared; undeclared use invalidates the attempt.
