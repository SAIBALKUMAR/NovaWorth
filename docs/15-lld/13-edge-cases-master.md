## Master Register Architecture & Conventions

Every unexpected state, race condition, hardware fault, and behavioral anomaly is cataloged using six standard operational facets:
1. **ID:** Strict hierarchical tag (`EC-[DOMAIN]-[001..NNN]`).
2. **Scenario:** The exact mechanical, network, or data fault condition.
3. **Detection:** Telemetry signals, database constraints, error codes, or threshold monitors that flag the incident.
4. **Handling:** Immediate automated system behavior (circuit breaks, rollbacks, fallbacks, defensive logging).
5. **Recovery:** Operational playbooks and manual human remediation required if automation is insufficient.
6. **Prevention:** Upstream architectural guards, validation layers, tests, or policies preventing recurrence.

## Domain 1: Authentication & Identity (EC-AUTH-001 to 020)

| ID | Scenario | Detection | Handling | Recovery | Prevention |
|---|---|---|---|---|---|
| EC-AUTH-001 | Passkey biometric enrollment fails mid-handshake | Client WebAuthn error `NotAllowedError` or timeout | Rolls back session creation; offers email magic link fallback | Support directs user to verify device biometric setup | Feature detect WebAuthn capabilities before rendering passkey UI |
| EC-AUTH-002 | Session cookie corrupted or cryptographic signature manipulated | Lucia Auth middleware throws `InvalidSessionId` | Invalidates cookie, clears client storage, redirects to `/login` | None required; user logs in cleanly | Enforce `SameSite=Strict`, `Secure`, `HttpOnly` attributes |
| EC-AUTH-003 | Token rotation race condition across multiple browser tabs | Concurrent requests present identical refresh token | Mutex lock in Redis allows first tab to rotate; secondary tab receives updated token | Tab refreshes state; if refresh token replay detected, invalidate family | Distribute atomic rotation via Redis key leases |
| EC-AUTH-004 | Neon Postgres auth table locked during schema migration | Query latency exceeds 3,000ms or returns `55P03` | In-memory Redis cached session validation serves read traffic | On-call engineer cancels blocking DDL migration | Run all schema migrations with `SET lock_timeout = '2s'` |
| EC-AUTH-005 | Lucia Auth session expires during high-stakes gate exam | Middleware flags expired timestamp during auto-save | Grants 15-minute exam grace extension; prompts re-auth modal without unmounting exam | Learner inputs password/passkey in modal; attempt state preserved | Auto-refresh active sessions when active gate telemetry detected |
| EC-AUTH-006 | Rate limit tripped on password reset emails (Resend free tier 3k/mo limit hit) | Resend API returns HTTP 429 or quota error | Diverts to backup SMTP relay (Hetzner local Postfix); alerts ops | Devops switches DNS SPF/DKIM to backup provider | Daily monitoring alert at 80% monthly Resend quota |
| EC-AUTH-007 | Disposable / temporary email domain detected at signup | Email domain matched against disposable domain blocklist | Blocks registration with user error: "Please use a permanent email" | Manual whitelist override in Admin CMS if corporate domain falsely flagged | Maintain automated daily sync with open-source disposable email lists |
| EC-AUTH-008 | Guardian consent revoked for minor account | Guardian dashboard executes revoke action | Revokes minor write tokens; freezes wallet spending; enables read-only study | Support confirms guardian identity if requested by minor | Require dual verification (email + SMS) for guardian revocation |
| EC-AUTH-009 | Concurrent login from disparate geographic IPs (>1000km in <10m) | GeoIP lookup calculates impossible travel velocity | Terminates both sessions; flags account for verification; sends security email | User verifies identity via email code and sets new passkey | Store GeoIP coordinate history in Redis sliding window |
| EC-AUTH-010 | Third-party OAuth provider (Google/GitHub) outage | OAuth callback returns HTTP 500 or timeout | Displays "Sign in with email link" option; retains partial session state | User signs in via email; provider status page monitored | Support multiple sign-in methods linked to single pseudonymous ID |
| EC-AUTH-011 | Learner changes email address while active sessions exist | Email update mutation executed | Sends verification link to new email; keeps old email active until confirmed | User verifies new address; all older sessions invalidated | Require current password or biometric passkey before email mutation |
| EC-AUTH-012 | Brute-force credential stuffing against Lucia endpoint | > 5 failed logins within 60s from single IP | IP throttled for 15 minutes; CAPTCHA challenged via Cloudflare Turnstile | Blocked IPs cleared automatically after backoff window | Rate limit login endpoint at Caddy/Cloudflare edge (max 10 req/min) |
| EC-AUTH-013 | Learner loses passkey device and has no recovery key | Learner contacts support with recovery failure | Enforces 72-hour security lockout; sends recovery challenge to verified email | Support agent reviews identity proof; triggers account recovery token | Force learners to download PDF emergency recovery keys upon passkey creation |
| EC-AUTH-014 | Neon connection timeout during auth credential verification | Postgres connection pool exhausted | Serves HTTP 503 with retry-after header (3s) | Cloud operations checks Neon connection pooler capacity | Provision PgBouncer mode with 5,000 pooled connection limit |
| EC-AUTH-015 | JWT signature verification fails due to secret key rotation | Worker receives token signed by retired key | Middleware attempts verification against secondary previous key | If both fail, user redirected to re-authenticate | Support dual-key verification window during 24-hour rotation cycle |
| EC-AUTH-016 | Incomplete 2FA challenge abandoned mid-session | Partial auth token idle for > 5 minutes | Invalidates partial state in Redis; purges challenge token | Learner restarts authentication flow | 5-minute hard TTL on all intermediate 2FA challenge tokens |
| EC-AUTH-017 | User signs in with secondary alias linked to existing account | Auth service matches secondary email in alias table | Automatically merges identity; updates primary audit log | None required; user seamlessly enters account | Strict unique index on normalized email hashes |
| EC-AUTH-018 | Lucia database adapter connection pool starvation | Neon query latency spikes > 2,000ms | Failover to read replica for session lookups; writes buffer in Redis | SRE investigates long-running analytical queries blocking connection slots | Separate transactional auth pool from analytical worker pool |
| EC-AUTH-019 | Session revived after user deletion scheduled | Scheduled deletion flag present on user record | Blocks login; displays "Account scheduled for deletion. Cancel deletion?" | User can cancel deletion within 14-day grace period | Middleware checks `deleted_at IS NOT NULL` before session emission |
| EC-AUTH-020 | Stolen session token replay attempt from differing user-agent | User-Agent or TLS client fingerprint diverges from session | Drops request; revokes session; logs SEV2 security event | User re-authenticates and receives security alert email | Bind session tokens to client TLS fingerprint and device profile |
