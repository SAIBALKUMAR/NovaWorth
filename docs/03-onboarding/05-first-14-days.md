# First 14 Days

## 1. Goal

The first 14 days decide whether the learner forms a habit. The design target:

- **D0:** complete onboarding + first mission.
- **D1:** return and pass level 1.
- **D7:** pass 3–5 levels and feel a real skill shift.
- **D14:** establish a weekly rhythm and choose a longer path.

**Activation event:** first verified level pass, not signup.

---

## 2. Day-by-day plan

### Day 0 — First win
- Onboarding (8–12 min).
- Recommendation reveal.
- First mission (5–10 min): a real level-1 task.
- Immediate feedback.
- "Here is your next step" (one, not five).
- Optional: add a calendar reminder.

**Success:** first mission completed; learner can explain what they learned.

### Day 1 — First gate
- 10-minute practice review.
- Level 1 gate (10–15 min).
- First XP + EC award.
- Wallet reveal: "This is what you earned and why."
- Choose a daily time (morning/lunch/evening).

**Success:** level 1 passed; wallet understood.

### Day 2 — Habit anchor
- 10-minute retrieval practice.
- One new concept.
- "Streak" replaced by **momentum**: 3 sessions/week, not daily pressure.
- Optional guild suggestion.

**Success:** second session completed.

### Day 3 — Experience check-in
- One micro-question: "What did you do this week?"
- Update experience graph.
- Adjust recommendation if needed.
- Level 2 practice.

**Success:** profile updated; learner feels known.

### Day 4 — Modality variety
- Try a different format: video, role-play, or sim.
- Ask: "Which format helped most?"
- Adapt the next session.

**Success:** modality preference captured; completion.

### Day 5 — Quick win
- A short, satisfying task that produces a visible artifact.
- Share option (private by default).
- Level 2 gate if ready.

**Success:** artifact created; confidence up.

### Day 6 — Rest / reflect
- No new content.
- 5-minute reflection: "What clicked? What is still fuzzy?"
- Spaced review of 5 items.
- Wellbeing check.

**Success:** reflection completed; no guilt for resting.

### Day 7 — Week 1 review
- Show progress: levels, XP, EC, time.
- Show one thing they can now do that they could not before.
- Set next week's goal (2–3 sessions).
- Recommend a guild or study buddy (optional).

**Success:** week-1 review viewed; next goal set.

### Day 8 — Deeper practice
- First applied task with a rubric.
- Feedback with one specific improvement.
- Level 3 practice.

**Success:** applied task submitted.

### Day 9 — Social proof (optional)
- See anonymized examples of what peers built.
- Join a guild or follow a skill.
- No public leaderboard pressure.

**Success:** social action or explicit opt-out.

### Day 10 — Challenge stretch
- One above-level problem (optional).
- Mastery multiplier opportunity.
- "Too hard?" → scaffolded version.

**Success:** stretch attempted; no shame on skip.

### Day 11 — Spaced review
- Review queue: 10–15 items.
- Identify weak spots.
- Adjust plan.

**Success:** review completed; weak spots addressed.

### Day 12 — Real-world application
- Apply the skill in the learner's life.
- Submit a photo, note, or artifact.
- Reflect on what happened.

**Success:** real-world evidence submitted.

### Day 13 — Path decision
- Review fit: "Is this the right skill for the next 90 days?"
- Options: continue, add secondary, switch, sample.
- No penalty for switching.

**Success:** path decision made.

### Day 14 — Two-week review
- Progress dashboard.
- EC earned and redeemed (if any).
- Next 30-day plan.
- Invite to a cohort or guild.
- Feedback survey (3 questions).

**Success:** plan accepted; D14 retention.

## 3. Session design

### 3.1 Micro-session (10 min)
- 2-min review.
- 5-min new concept.
- 3-min practice.
- 1-min reflection.

### 3.2 Standard session (25 min)
- 5-min review.
- 10-min learn.
- 8-min practice.
- 2-min reflection.

### 3.3 Deep session (60 min)
- 10-min review.
- 20-min learn.
- 25-min applied task.
- 5-min reflection.

### 3.4 Rules
- Always end with a visible win or a clear next step.
- Never end on a paywall.
- Never punish a missed day.
- Offer a 2-minute version when time is short.

## 4. Notifications

| Day | Notification | Content | Cap |
|---|---|---|---|
| D0 | Welcome | "Your first mission is ready" | 1 |
| D1 | First gate | "10 minutes to level 1" | 1 |
| D2 | Momentum | "A 10-minute session keeps you moving" | 1 |
| D3 | Check-in | "What did you do this week?" | 1 |
| D5 | Quick win | "A 5-minute win is waiting" | 1 |
| D7 | Review | "Your week in learning" | 1 |
| D14 | Path | "Ready to choose your 90-day path?" | 1 |

Rules:
- Max 1 learning notification/day.
- Quiet hours respected.
- Easy unsubscribe.
- No streak-shaming.
- No fake urgency.

## 5. Rewards in the first 14 days

| Event | XP | EC | Note |
|---|---|---|---|
| First mission | 25 | 0 | No EC until gate |
| Level 1 pass | 100 | 10 | First wallet moment |
| Level 2 pass | 283 | 22 | Momentum |
| Level 3 pass | 520 | 36 | — |
| First applied task | 100 | 15 | Bonus |
| Week 1 review | 50 | 5 | Reflection |
| Day 14 review | 100 | 10 | Retention |
| First real-world evidence | 150 | 25 | Transfer |

No EC for logging in, watching, or streak length.

---

## 6. Drop-off recovery

| Drop-off point | Trigger | Intervention |
|---|---|---|
| After consent | 24h inactivity | One email: "Your path is waiting" |
| During work history | Abandon | Save + resume link; shorten to 3 questions |
| After diagnostic | No skill chosen | Show 3 recommendations + sampler |
| After first mission | No return | "Your next 10 minutes" + calendar |
| After first failed gate | Frustration | Feedback + retry plan + human help |
| Day 3–5 | Habit gap | 2-minute session + peer nudge |
| Day 7 | No review | Simplified review + wellbeing check |

Recovery is limited to 3 messages; then respect silence.

---

## 7. Accessibility and low bandwidth

- Text-only mode from day 0.
- Offline packs for the first 3 levels.
- Audio version of each concept.
- Captions/transcripts.
- Screen-reader-tested first mission.
- No video-only gate.

---

## 8. Metrics

| Metric | Target |
|---|---|
| D0 first mission completion | ≥70% |
| D1 return | ≥55% |
| D7 return | ≥40% |
| D14 return | ≥30% |
| First level pass within 7 days | ≥50% |
| 3+ levels in 14 days | ≥35% |
| Notification opt-out | <10% |
| Learner-reported overwhelm | <10% |
| Accessibility blockers | 0 |

---

## 9. Requirements

- `FR-ONB-401`: The first mission is a real level-1 task.
- `FR-ONB-402`: The first gate is reachable within 24 hours.
- `FR-ONB-403`: The wallet explains every award.
- `FR-ONB-404`: A 2-minute session exists for every active level.
- `FR-ONB-405`: Notifications are capped and user-controlled.
- `FR-ONB-406`: Missed days do not reduce XP or EC.
- `FR-ONB-407`: Drop-off recovery respects opt-out.
- `FR-ONB-408`: Day 14 offers a 30-day plan.
- `FR-ONB-409`: The learner can switch paths without penalty.
- `FR-ONB-410`: All first-14-day content works offline.
